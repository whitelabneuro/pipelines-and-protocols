# Splicing pipelines

This section is intended for workflows related to splicing analysis in White Lab.

Over time, this may include:

- differential splicing workflows
- exon and isoform usage pipelines
- event-based splicing analysis
- integrative splicing and transcriptomic analysis
- project-specific splicing workflow variants where appropriate

## Suggested contents

A pipeline in this section should ideally include:

- a clear description of purpose
- expected inputs and outputs
- software and reference requirements
- usage notes
- version information
- links to associated projects, datasets or publications where relevant

## Notes

This section can be used for both reusable workflows and structured documentation for evolving splicing analysis approaches.
