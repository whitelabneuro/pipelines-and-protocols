# Long-read pipelines

This section is intended for workflows related to long-read sequencing analysis in White Lab.

Over time, this may include:

- isoform analysis workflows
- transcript reconstruction pipelines
- long-read QC and preprocessing workflows
- integrative short-read and long-read analysis approaches
- project-specific long-read workflow variants where appropriate

## Suggested contents

A pipeline in this section should ideally include:

- a short description of purpose
- expected inputs and outputs
- software and environment requirements
- usage notes
- version information
- links to associated projects, datasets or publications where relevant

## Notes

This section can support both exploratory development and more formalised workflows linked to datasets or manuscripts.
