# Single-cell pipelines

This section is intended for workflows related to single-cell analysis in White Lab.

Over time, this may include:

- preprocessing and QC workflows
- cell annotation workflows
- integration and clustering pipelines
- perturbation analysis workflows
- project-specific single-cell workflow variants where appropriate

## Suggested contents

A pipeline in this section should ideally include:

- a short description of purpose
- expected inputs and outputs
- software and environment requirements
- usage notes
- version information
- links to associated projects, datasets or publications where relevant

## Notes

This section may cover both short-read single-cell workflows and integrative analyses linked to other sequencing approaches.
