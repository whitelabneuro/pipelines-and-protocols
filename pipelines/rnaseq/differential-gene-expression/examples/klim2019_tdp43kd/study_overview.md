## Downstream analysis purpose

This downstream example is intended to show how White Lab retained preprocessing outputs are used as the starting point for structured differential gene expression analysis using `nf-core/differentialabundance`.

The example is also intended to support:

- training
- workflow validation
- repo development
- later CREATE-based real-run demonstration
