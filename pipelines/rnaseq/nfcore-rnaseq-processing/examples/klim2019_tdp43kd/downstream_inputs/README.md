# Downstream input records

This folder contains small manifest-style files that help later downstream workflows understand the retained outputs from the Klim worked example.

## Included files

- `samplesheet_with_bams.csv` — samplesheet linking sample IDs to retained BAM outputs
- `run_manifest.txt` — launcher-generated run provenance record for the completed primary processing run

These files are retained in the repo because they are small, informative, and useful for future worked-example pipeline development.
