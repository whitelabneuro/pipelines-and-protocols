# Klim et al. 2019 TDP-43 knockdown dataset

Representative development dataset used to build and test the White Lab short-read RNA-seq intake pipeline.

## Source
Klim et al. 2019
PMID: 30643292

## Biological context
Human iPSC-derived motor neurons with TDP-43 knockdown.

## Purpose in this repository
This dataset is used only as a representative public test case for pipeline development and documentation.

It should not define the reusable core structure of the workflow.
