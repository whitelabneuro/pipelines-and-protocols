# Projects

This directory contains resources linked to specific projects, datasets or manuscripts.

Over time, these folders may be used to record:

- short project summaries
- related workflows or protocol versions
- metadata about analysis runs
- links to figures, datasets or publications where appropriate

## Purpose

This section is intended to support traceability between research outputs and the methods used to generate them.

## Suggested project folder structure

```text
project-name/
├── README.md
├── metadata/
├── analysis-notes/
├── linked-pipelines.md
└── linked-protocols.md
