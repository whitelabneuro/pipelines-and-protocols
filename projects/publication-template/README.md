# Publication template

This folder provides a simple template for organising resources linked to a specific project, dataset or manuscript.

## Purpose

The aim is to make it easier to connect:

- project overview
- associated datasets
- protocol versions
- pipeline versions
- figures or outputs
- manuscript-linked notes

## Suggested structure

```text
publication-template/
├── README.md
├── metadata/
├── analysis-notes/
├── linked-pipelines.md
└── linked-protocols.md
