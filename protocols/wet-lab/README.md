# Wet-lab protocols

This section is intended for version-controlled wet-lab protocols used in White Lab.

Over time, this may include protocols related to:

- human stem-cell culture
- neuronal differentiation
- organoid and assembloid work
- lentiviral workflows
- sample preparation for sequencing and downstream analysis

## Purpose

This section helps track how experimental methods evolve over time and supports consistency across projects and personnel.

## Notes

Not all protocols in active use will necessarily be made public in full. Public-facing materials can be shared where appropriate.
