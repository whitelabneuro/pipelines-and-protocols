# Publication-linked protocols

This section is intended for protocol versions linked to specific datasets, figures, manuscripts or published studies.

## Purpose

The aim of this section is to support traceability between research outputs and the methods used to generate them.

Where appropriate, this may include:

- protocol versions associated with a manuscript
- method summaries linked to a dataset or figure
- notes on important methodological adaptations made within a project
- references to related computational workflows or analysis pipelines

## Suggested use

A publication-linked protocol folder may be organised by project, manuscript or study.

For example:

```text
publication-linked/
├── project-name/
│   ├── README.md
│   ├── wet-lab-method-notes.md
│   ├── computational-method-notes.md
│   └── linked-resources.md
